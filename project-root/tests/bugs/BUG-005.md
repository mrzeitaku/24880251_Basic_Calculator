# BUG-005: Sai kết quả với số rất lớn

## Found by Test Case
TC-CALC-025; TC-ERROR-007

## Requirement liên quan
FR-CALC-25; FR-ERROR-07

## Severity / Priority
- **Severity:** Critical
- **Priority:** P1

## Environment
- **URL:** https://testsheepnz.github.io/BasicCalculator.html
- **Build / Prototype Version:** Prototype
- **Browser:** VS Code integrated browser

## Steps to Reproduce
1. Nhập First number = `999999999999`.
2. Nhập Second number = `1`.
3. Chọn Operation = `Add`.
4. Bấm `Calculate`.

## Expected Result
Answer là `1000000000000` hoặc hệ thống từ chối dữ liệu với thông báo rõ ràng.

## Actual Result
Answer hiển thị `10000000000`.

## Evidence
Observed during automated browser execution on 2026-09-14.
