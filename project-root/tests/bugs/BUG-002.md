# BUG-002: First number rỗng bị xử lý như 0

## Found by Test Case
TC-CALC-016; TC-ERROR-008

## Requirement liên quan
FR-CALC-16; FR-ERROR-08

## Severity / Priority
- **Severity:** Major
- **Priority:** P1

## Environment
- **URL:** https://testsheepnz.github.io/BasicCalculator.html
- **Build / Prototype Version:** Prototype
- **Browser:** VS Code integrated browser

## Steps to Reproduce
1. Để trống First number.
2. Nhập Second number = `10`.
3. Chọn Operation = `Add`.
4. Bấm `Calculate`.

## Expected Result
Hệ thống hiển thị lỗi First number bắt buộc.

## Actual Result
Hệ thống xử lý First number rỗng như giá trị `0` và trả về `10`.

## Evidence
Observed during automated browser execution on 2026-09-14.
