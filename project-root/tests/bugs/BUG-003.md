# BUG-003: Second number rỗng bị xử lý như 0

## Found by Test Case
TC-CALC-017; TC-ERROR-009

## Requirement liên quan
FR-CALC-17; FR-ERROR-09

## Severity / Priority
- **Severity:** Major
- **Priority:** P1

## Environment
- **URL:** https://testsheepnz.github.io/BasicCalculator.html
- **Build / Prototype Version:** Prototype
- **Browser:** VS Code integrated browser

## Steps to Reproduce
1. Nhập First number = `10`.
2. Để trống Second number.
3. Chọn Operation = `Add`.
4. Bấm `Calculate`.

## Expected Result
Hệ thống hiển thị lỗi Second number bắt buộc.

## Actual Result
Hệ thống xử lý Second number rỗng như giá trị `0` và trả về `10`.

## Evidence
Observed during automated browser execution on 2026-09-14.
