# BUG-006: Clear không xóa các ô nhập số

## Found by Test Case
TC-CALC-026; TC-UI-006

## Requirement liên quan
FR-CALC-26; FR-UI-06

## Severity / Priority
- **Severity:** Major
- **Priority:** P2

## Environment
- **URL:** https://testsheepnz.github.io/BasicCalculator.html
- **Build / Prototype Version:** Prototype
- **Browser:** VS Code integrated browser

## Steps to Reproduce
1. Nhập First number = `5`.
2. Nhập Second number = `10`.
3. Bấm `Calculate`.
4. Bấm `Clear`.

## Expected Result
First number, Second number và Answer đều được xóa.

## Actual Result
Answer được xóa nhưng First number vẫn là `5` và Second number vẫn là `10`.

## Evidence
Observed during automated browser execution on 2026-09-14.
