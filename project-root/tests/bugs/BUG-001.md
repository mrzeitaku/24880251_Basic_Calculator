# BUG-001: Chia cho 0 làm trạng thái tính toán bị khóa

## Found by Test Case
TC-CALC-002; TC-ERROR-001

## Requirement liên quan
FR-CALC-02; FR-ERROR-01

## Severity / Priority
- **Severity:** Major
- **Priority:** P1

## Environment
- **URL:** https://testsheepnz.github.io/BasicCalculator.html
- **Build / Prototype Version:** Prototype
- **Browser:** VS Code integrated browser

## Steps to Reproduce
1. Nhập First number = `10`.
2. Nhập Second number = `0`.
3. Chọn Operation = `Divide`.
4. Bấm `Calculate`.

## Expected Result
Hệ thống hiển thị lỗi chia cho 0 và giữ giao diện có thể tiếp tục thao tác.

## Actual Result
Hệ thống hiển thị `Divide by zero error!` nhưng vẫn giữ trạng thái `Calculating ...` và nút Calculate bị disabled.

## Evidence
Observed during automated browser execution on 2026-09-14.
