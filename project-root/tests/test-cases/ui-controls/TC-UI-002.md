# TC-UI-002: Bật Integers only

## Requirement ID

FR-UI-02

## Module / Test type / Technique

UI Controls / Functional / Decision Table

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.

## Test data

| Parameter | Value |
|---|---|
| First number | 7 |
| Second number | 2 |
| Operation | Divide |
| Integers only | Checked |

## Test steps

1. Nhập `7` và `2`.
2. Chọn `Divide`.
3. Bật `Integers only`.
4. Bấm `Calculate`.

## Expected result

Answer hiển thị `3` theo chế độ số nguyên.

## Status / Related bugs

Pass / None
