# TC-CALC-034: Chuyển đổi Build

## Requirement ID

FR-CALC-34

## Module / Test type / Technique

Calculator / Compatibility / Configuration Testing

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype đang được chọn.

## Test data

| Parameter | Value |
|---|---|
| Initial build | Prototype |
| Target build | 1 |

## Test steps

1. Mở danh sách Build.
2. Chọn build `1`.
3. Chờ trang tải lại.
4. Kiểm tra các control Calculator vẫn hiển thị.

## Expected result

Build `1` được chọn, trang tải hoàn tất và các control First number, Second number, Operation, Calculate vẫn sử dụng được.
