# TC-CALC-011: Chia số âm cho số dương

## Requirement ID

FR-CALC-11

## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.

## Test data

| Parameter | Value |
|---|---|
| First number | -20 |
| Second number | 5 |
| Operation | Divide |

## Test steps

1. Nhập `-20` vào First number.
2. Nhập `5` vào Second number.
3. Chọn `Divide`.
4. Bấm `Calculate`.

## Expected result

Answer hiển thị `-4`.
