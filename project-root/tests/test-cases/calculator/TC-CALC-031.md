# TC-CALC-031: Chọn phép toán Multiply

## Requirement ID

FR-CALC-31

## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.

## Test data

| Parameter | Value |
|---|---|
| First number | 12 |
| Second number | 8 |
| Operation | Multiply |

## Test steps

1. Nhập `12` và `8`.
2. Chọn `Multiply`.
3. Bấm `Calculate`.

## Expected result

Answer hiển thị `96`.

## Status / Related bugs

Pass / None
