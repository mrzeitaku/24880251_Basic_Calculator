## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

- Trang Basic Calculator được mở.
- Build Prototype được chọn.

## Test data

| Parameter | Value |
|---|---|
| First number | 12 |
| Second number | 4 |
| Operation | Divide |

1. Nhập `12` và `4`.
2. Chọn `Divide`.
3. Bấm `Calculate`.

Answer hiển thị `3` và không có thông báo lỗi.
