# TC-CALC-023: Nhập số âm hợp lệ

## Requirement ID

FR-CALC-23

## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.
- Phép toán `Add` được chọn.

## Test data

| Parameter | Value |
|---|---|
| First number | -12 |
| Second number | 5 |
| Operation | Add |

## Test steps

1. Nhập `-12` vào First number.
2. Nhập `5` vào Second number.
3. Bấm `Calculate`.

## Expected result

Dữ liệu được chấp nhận và Answer hiển thị `-7`.
