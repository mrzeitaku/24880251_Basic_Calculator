# TC-CALC-012: Cộng hai số thập phân

## Requirement ID

FR-CALC-12

## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.
- Tùy chọn `Integers only` tắt.

## Test data

| Parameter | Value |
|---|---|
| First number | 2.5 |
| Second number | 1.25 |
| Operation | Add |

## Test steps

1. Nhập `2.5` vào First number.
2. Nhập `1.25` vào Second number.
3. Chọn `Add`.
4. Bấm `Calculate`.

## Expected result

Answer hiển thị giá trị số `3.75`.

## Status / Related bugs

Pass / None
