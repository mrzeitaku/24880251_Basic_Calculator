# TC-CALC-022: Nhập số thập phân hợp lệ

## Requirement ID

FR-CALC-22

## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.
- `Integers only` tắt.

## Test data

| Parameter | Value |
|---|---|
| First number | 1.5 |
| Second number | 2.5 |
| Operation | Add |

## Test steps

1. Nhập `1.5` vào First number.
2. Nhập `2.5` vào Second number.
3. Chọn `Add`.
4. Bấm `Calculate`.

## Expected result

Dữ liệu được chấp nhận và Answer hiển thị `4`.

## Status / Related bugs

Pass / None
