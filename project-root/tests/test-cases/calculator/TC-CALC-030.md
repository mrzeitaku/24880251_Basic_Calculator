# TC-CALC-030: Chọn phép toán Subtract

## Requirement ID

FR-CALC-30

## Module / Test type / Technique

Calculator / Functional / Equivalence Partitioning

## Preconditions

- Trang Basic Calculator được mở.
- Build Prototype được chọn.

## Test data

| Parameter | Value |
|---|---|
| First number | 12 |
| Second number | 8 |
| Operation | Subtract |

## Test steps

1. Nhập `12` và `8`.
2. Chọn `Subtract`.
3. Bấm `Calculate`.

## Expected result

Answer hiển thị `4`.
