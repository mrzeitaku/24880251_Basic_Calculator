# Error Handling Test Cases

Module code: `ERROR`

Test case naming: `TC-ERROR-[NUMBER]`.

Scope: divide-by-zero, invalid input, empty input, oversized values, and recovery after errors.

Số lượng: 10 test case (`TC-ERROR-001` đến `TC-ERROR-010`).

Execution status: 5 Pass, 5 Fail. Các case Fail liên kết Bug `BUG-001`, `BUG-002`, `BUG-003`, `BUG-004` và `BUG-005`.
